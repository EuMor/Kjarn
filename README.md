# Kjarn Engine

**Kjarn** — экспериментальный игровой движок на C++ с упором на лёгкость, модульность и визуальное создание игр.

Проект находится на ранней стадии разработки. Сейчас формируется базовая архитектура движка и его основные подсистемы.

## Текущий статус

На данный момент в проекте ведётся работа над фундаментом движка:

- базовая структура Core;
- создание и управление окном приложения;
- обработка пользовательского ввода;
- система времени;
- базовая камера;
- начальная реализация Renderer;
- сборка проекта с помощью CMake.

**Важно:** перечисленные возможности находятся в разработке. Полноценный визуальный редактор и инструменты создания игр ещё не реализованы.

## Технологии

- **Язык:** C++
- **Стандарт:** C++20
- **Система сборки:** CMake 3.20+
- **Основная IDE:** Visual Studio 2022
- **Текущая платформа:** Windows
- **Компилятор:** MSVC

### Core

## Сборка в Visual Studio

Для работы потребуется:

- Visual Studio 2022;
- компонент **Desktop development with C++**;
- CMake 3.20 или новее.

### Открытие проекта

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/EuMor/Kjarn.git
   ```

2. Запустите Visual Studio.
3. Выберите **File → Open → Folder**.
4. Укажите папку `Kjarn`, в которой находится корневой `CMakeLists.txt`.
5. Дождитесь завершения конфигурации CMake.
6. Выберите исполняемую цель `Kjarn` и запустите её через **Start** или `F5`.

Visual Studio самостоятельно обнаружит CMake-проект и подготовит конфигурацию сборки.

## Сборка через командную строку

Из корневой папки проекта:

```bash
cmake -S . -B build
cmake --build build --config Debug
```

Для Release:

```bash
cmake --build build --config Release
```

## Разработка

При разработке используются предупреждения компилятора:

- MSVC: `/W4`, `/permissive-`;
- GCC/Clang: `-Wall`, `-Wextra`, `-Wpedantic`.

Изменения желательно делать небольшими и логически завершёнными. Перед отправкой изменений необходимо убедиться, что проект собирается.

## Направление развития

Основная цель Kjarn — предоставить пользователю возможность создавать игры преимущественно через визуальный редактор, не требуя обязательного написания кода.

Планируемые направления развития:

- модульная архитектура движка;
- 2D Runtime;
- визуальный редактор;
- система сцен и игровых объектов;
- тайловые карты;
- визуальная система логики;
- расширение возможностей через скрипты;
- дальнейшая подготовка архитектуры к 3D.

Подробный план развития будет поддерживаться отдельно от README.
